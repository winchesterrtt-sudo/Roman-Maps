About this map

The Roman Empire at its height in AD 125: provinces, main and minor roads, settlements, legionary fortresses, and the peoples and kingdoms beyond the frontiers. The full print edition is 68 × 47 inches; this viewer shows it at 300 dpi, so every label can be read.

Using the viewer

  • Scroll the mouse wheel, pinch, or use the + and − buttons to zoom.
  • Drag to move around. The small overview map shows where you are.
  • The house button resets the view; the corner button goes fullscreen.

Data sources
